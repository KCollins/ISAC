This directory contains hardware source files.

### OpenOBS Sensor Heads
These are all designed to use with Adafruit carrier boards. They do not include any spots for a pressure board, since for our application we're only interested in backscatter.
 - **SensorCapV11.stl**: Suitable for the [VCNL4010](https://www.adafruit.com/product/466?srsltid=AU7gw4UTuG5I8HEObkcyDNkkXtAUzCGb80vCChXrD3bDop7IK6JsJFDD), which is the board used (and validated) in Ted Langhorst's original design.
 - **SensorCapV17.stl**: Suitable for the VCNL4020, 4030, 4040.
